# Preface

This directory contains human-run system test material, not implementation design. Read it when planning or recording manual product validation.

Read the top-level `.kb/agents.md` file before continuing below.

# Important

- Keep procedures executable by a human tester without repository archaeology.
- Keep sample passages stable so results remain comparable.
- Do not add architecture decisions, protocol details, task tracking, meeting notes, or implementation plans here.
- Put durable agent knowledge in the nearest subsystem `.kb/` directory.

# Directory

- `test-plan/test-plan-system.md` - End-user accuracy, performance, desktop, and security test procedure.
- `test-plan/test-samples-*.md` - Stable multilingual passages used by the system test procedure.
